# VelocityLeads

Plataforma de geração de leads B2B e prospecção de empresas. Encontre empresas reais por ramo de atividade, estado, cidade e bairro — com telefone, e-mail e WhatsApp — enriqueça os dados e faça prospecção automatizada por WhatsApp e e-mail.

## Funcionalidades

- Busca de empresas por ramo, estado, cidade e bairro (cobertura nacional)
- Leads com telefone, e-mail e WhatsApp
- Enriquecimento de dados
- Prospecção automatizada por WhatsApp
- Campanhas de e-mail marketing
- CRM integrado estilo Kanban
- Add-ons e pacotes com pagamento via Mercado Pago

## Stack

- Vite + React + TypeScript
- Tailwind CSS + shadcn/ui
- Supabase (Postgres, Auth, Edge Functions)

## Desenvolvimento

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```
